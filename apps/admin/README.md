# @gig/admin — Next.js admin dashboard (placeholder)

**Status: not yet scaffolded.** This directory is reserved for the platform
admin web app (Next.js).

The app will be generated when the first admin surface ships (category
management + platform settings, Phase 4) using the official generator
(`npx create-next-app`) against the then-current Next.js version, per the
project rule to never guess external dependency versions from memory.

Planned scope (docs/product/MVP_SCOPE.md §Admin): overview KPIs, user
search/suspend/restore, job investigation, restricted-job review queue,
payment state viewer, dispute resolution, report review, category management,
platform settings — every mutation audited, admin auth with TOTP 2FA.
